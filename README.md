# DUPB Verbal Explorer

Interface web para consulta ao **Dicionário de usos do português do Brasil** (Francisco S. Borba, Ática, 2002).

## Release 1

- Entradas de consulta: **6.632**
- Acepções: **19.989**
- Predicadoras: **19.768**
- Não predicadoras: **221**
